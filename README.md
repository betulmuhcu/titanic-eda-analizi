# Titanic Veri Seti - Keşifçi Veri Analizi (EDA)

Bu projede Titanic veri seti üzerinde Python kullanılarak Keşifçi Veri Analizi (EDA) gerçekleştirilmiştir.

## Projenin Amacı

Titanic yolcularına ait demografik ve seyahat bilgilerini inceleyerek değişkenler ile hayatta kalma durumu arasındaki ilişkileri keşfetmek.

## Yapılan Analizler

* Veri setinin genel yapısının incelenmesi
* Kategorik değişkenlerin analizi
* Cinsiyet ve bilet sınıfına göre hayatta kalma oranlarının karşılaştırılması
* Eksik verilerin incelenmesi ve temizlenmesi
* `Title` değişkeninin oluşturulması
* `Age` eksik değerlerinin grup medyanları kullanılarak doldurulması
* `Cabin` bilgisinden `Deck` değişkeninin oluşturulması
* Değişkenler arasındaki ilişkilerin görselleştirilmesi

## Kullanılan Teknolojiler

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Proje Kapsamı

Bu çalışmada makine öğrenmesi modeli oluşturulmamıştır. Projenin odağı veri keşfi, veri temizleme ve özellik mühendisliğidir.

## Dosyalar

* `titanic-eda-analysis.ipynb` → Veri analizi ve görselleştirmelerin bulunduğu Jupyter Notebook
* `train.csv` → Analizde kullanılan Titanic veri seti
